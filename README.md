# 🏠 Predicción del precio de la vivienda — Alicante

Análisis y predicción del precio de la vivienda en Alicante mediante modelos tradicionales de Machine Learning, redes neuronales y modelos de lenguaje de gran escala (LLM).

Este repositorio contiene el código desarrollado para el Trabajo Fin de Máster, abarcando las diferentes etapas del proyecto, desde la recolección y el preprocesamiento de los datos hasta su análisis, modelización y enriquecimiento mediante técnicas de inteligencia artificial.

---

## 📋 Descripción

El proyecto se encuentra organizado en cuatro carpetas principales, correspondientes a las diferentes etapas del proceso:

### 📥 Recolección

Contiene el código empleado para la obtención de los datos de viviendas, así como el conjunto de datos resultante del proceso de recolección.

### 🧹 Preprocesamiento

Contiene el código desarrollado para la limpieza, transformación y preparación de los datos, junto con el conjunto de datos obtenido tras aplicar estas operaciones.

### 📊 Análisis

Contiene el código utilizado para realizar el análisis exploratorio de los datos, así como la implementación y evaluación del rendimiento de los diferentes modelos de Machine Learning y redes neuronales.

### 🧠 Enriquecimiento

Contiene el código empleado para la extracción y el procesamiento de las descripciones de los anuncios, así como para el enriquecimiento del conjunto de datos mediante un modelo de lenguaje de gran escala (LLM), concretamente Qwen.
